# organizador-arquivos-python# Organizador Automático de Arquivos

Projeto em Python que organiza arquivos automaticamente em pastas com base na extensão.

## Funcionalidades
- Organiza imagens (.jpg, .png, .jpeg)
- Organiza PDFs
- Organiza vídeos
- Organiza documentos (.docx, .txt)

## Tecnologias
- Python
- os
- shutil

## Como executar
1. Configure o caminho da pasta no arquivo `organizador.py`
2. Execute:

python organizador.py
